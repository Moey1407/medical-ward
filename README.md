# Ward Round

A cartoon ward-round game for the Wits GEMP 1 integrated exam: walk to the patient, clerk them, explain the mechanisms, order tests, treat, and answer pharmacology questions.

Marking runs entirely in the browser (a small on-device language model), so there's no account, no server and no cost.
